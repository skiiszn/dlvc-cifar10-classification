# Assignment 3 — Brain Tumor Detection with YOLO

Comparative analysis of YOLOv5m, YOLOv8m and YOLOv11m for brain tumor detection in MRI scans across four classes: Glioma, Meningioma, NoTumor, and Pituitary.

---

## Requirements

- Python 3.12
- NVIDIA GPU with CUDA (recommended)

Install dependencies:
```bash
pip install ultralytics pandas matplotlib pillow pyyaml
```

## Setup

### 1. Download the dataset

Download the **MRI for Brain Tumor with Bounding Boxes** dataset from Kaggle:  
https://www.kaggle.com/datasets/ahmedsorour1/mri-for-brain-tumor-with-bounding-boxes

Extract it so the folder structure looks like:
```
assignment_3/
└── data/
    ├── Train/
    │   ├── Glioma/images/ and labels/
    │   ├── Meningioma/
    │   ├── NoTumor/
    │   └── Pituitary/
    └── Val/
        └── (same structure)
```

### 2. Run preprocessing

From inside `assignment_3/`:
```bash
python preprocess_data.py
```

This generates the `processed/` folder with train/val/test splits and `data.yaml`.

---

## Training

Train all three models sequentially:
```bash
python train.py --batch 8 --workers 0
```

Train a single model:
```bash
python train.py --model yolov8 --batch 8 --workers 0
```

If training was interrupted and history CSVs are incomplete, rebuild them from the existing checkpoints:
```bash
python train.py --rebuild
```

Trained weights are saved to `assignment_3/checkpoints/<model>/`.

---

## Evaluation

Evaluate all three models on the test set:
```bash
python test.py
```

Evaluate a single model:
```bash
python test.py --model yolov5
```

## Notes

- Use `--workers 0` on Windows to avoid shared memory errors
- Reduce `--batch` to 8 or 4 if CUDA out of memory errors
- YOLOv11 weights use the filename `yolo11m.pt` (no 'v'), this is handled automatically
